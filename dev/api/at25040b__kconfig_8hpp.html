Detailed Description

Optional ESP-IDF layer: a Config built from the CONFIG_AT25040B_* Kconfig options.

Copyright
Copyright (c) 2026 The driver-at25040b authors. SPDX-License-Identifier: MIT

Include this header only where you want menuconfig to choose the defaults; the driver never includes it and no driver signature depends on it. Under ESP-IDF the values come from sdkconfig.h. Without Kconfig every option falls back to Config{}.

Kconfig writes a bool option set to "n" as an absent macro. The identity check is on by default, so its option is a "skip" option: an absent CONFIG_AT25040B_SKIP_WRITE_ENABLE_CHECK means the check runs, under ESP-IDF and outside it alike. Read and write verification is chosen per call (Verify), not here.

One configuration per program: the inline function below depends on the CONFIG_ macros, so every translation unit of one program must see the same values (ESP-IDF has one sdkconfig.h per build; each host test is its own program). No driver header includes this one (handbook KB-CPP20-018).
