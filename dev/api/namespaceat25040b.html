Bus requirements

What the AT25010B/020B/040B needs from the SPI bus (datasheet "Features", section 4.3 Table 4-3, section 5). A port and a board configuration check their settings against these with static_assert (handbook KB-CPP-123). The scalar limits hold over the whole supply range (1.8 V to 5.5 V); BusTimingAt() gives the faster limits of a higher supply.

◆ CtrlPin

enum class at25040b::CtrlPin : uint8_t
strong

Control pins the port may drive through the optional GpioSet() hook.

Idle level (handbook KB-HW-018): WP idles ACTIVE (pin low, writes blocked), the safe state of this pin. The port drives it low before it enables the pin's output and before the first transfer, so the chip never sees WP float high; the driver releases it only around a write.

Enumerator
WriteProtect 

WP, active low on the package pin. ACTIVE (pin low) blocks every write.

constexpr bool at25040b::kContinuousWord = false
inlineconstexpr

false: the chip accepts idle SCK time between the bytes of one transfer (a static design: t_WH and t_WL have no maximum, Table 4-3). CS must stay low for the whole instruction.
