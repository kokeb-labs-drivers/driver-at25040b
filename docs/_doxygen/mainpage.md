# AT25040B Driver API reference {#mainpage}

The classes, types and opcodes of the AT25040B driver (AT25010B, AT25020B, AT25040B), generated from the headers in `inc/`.

Start with at25040b::AT25040B, the driver, and at25040b::SpiInterface, the base of the port you write. Errors are
at25040b::Error inside at25040b::Result; the configuration is at25040b::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">AT25040B Driver
documentation</a>.
